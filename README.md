# ENSE 271 Group Project 2026
---
This repository contains the ENSE271 Design project for Group I.


### Description:

This project involves working with EnviroCollective Network to design and develop a website using a people-centred design process.


### Team Members of Group I:

- Hyfa Sonia Mirembe
- Favi Alarcon

### Project Goals:
1. To create a visually appealing hub with clear and simple structure and navigation that can easily be managed by staff.
2. To reflect the programs ECN runs today.
3. To make searching the resource library and e-newsletter issues easy.
